# 视频切片 FastAPI 服务接口文档

| 项 | 值 |
|---|---|
| 版本 | API v1（文档修订 **2026-07-23**，基于本机真实联调） |
| 实测 Base URL | `http://127.0.0.1:8010`（生产替换为实际 API Origin，如 `http://39.108.184.150:8010`） |
| 交互式文档 | `/docs` · `/redoc` |
| OpenAPI 契约 | [`docs/openapi/v1.yaml`](openapi/v1.yaml) |
| 映射说明 | [`docs/api-mapping.md`](api-mapping.md) |
| 前端 | 本仓 `frontend/reference-ui/`（当前唯一保留的完整交互前端） |

口播/成片切片：OSS 或公网 URL 导入源片 → 手动切分 / 自动分镜 → 切割到源目录 `clips/` → 返回 OSS 对象列表。

| 项 | 说明 |
|---|---|
| 公开面 | `/api/v1/*` |
| 主键 | `video_id` / `job_id` / `segment_id` 均为标准 UUID |
| 响应 | JSON 统一 `{code, message, data}`；二进制不包 envelope |
| 异步 | import / manual / auto / cut 均为提交后轮询 |
| 运行模型 | **单 API 进程内存账本**（无 Postgres/Redis/Celery）；**重启后旧 ID 全部失效** |
| 鉴权 | **无 Token**；勿对公网裸暴露 |

### 本次实测样例（2026-07-23）

- 导入方式：`url` = `https://example-bucket.oss-cn-region.aliyuncs.com/source_media/1.mp4`
- 片长 **30.66 s**，**2160×3840**（竖屏），**29.97 fps**，**h264**，约 **104.4 MB**，`has_audio=false`
- `preview_url`（url 导入）= 后端生成的受管 OSS 媒体入口；优先 CDN，CDN 不可用时回退 OSS 签名 URL
- `filmstrip_url` = API 入口，响应 302 到 OSS 派生资源
- 切片 `oss_url`：优先为 `{OSS_CDN_BASE}/{oss_key}`；CDN 不可用时为 OSS 签名 URL

## 一、接口概览

### 1.1 能力

- 健康检查（含 `git_sha` / `build_time`）
- 源片异步导入：`oss_key`（配置桶）或 `url`（SSRF 校验后流式转存到受管 OSS）
- 手动切片（ready 后建档即切割）
- 自动分镜（ready 后建档即检测 → `preview` → `/cut`）
- 任务轮询、按视频列任务
- 返回全部及选中切片 OSS 对象（不执行媒资库复制）
- 二进制：源片 `/media`、胶片 `/filmstrip`、片段 `/preview|/thumb|/download`

### 1.2 公开路由

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 服务信息 |
| GET | `/api/v1/health` | 健康检查 |
| POST | `/api/v1/videos/import` | 提交导入（立刻返回） |
| GET | `/api/v1/videos/{video_id}` | 轮询导入 / 完整 Video |
| DELETE | `/api/v1/videos/{video_id}` | 删除视频 |
| GET | `/api/v1/videos/{video_id}/media` | 源片 mp4（隐藏；须 ready） |
| GET | `/api/v1/videos/{video_id}/filmstrip` | 胶片条 JPEG（隐藏；须 ready） |
| GET | `/api/v1/videos/{video_id}/jobs` | 该视频 Job 列表 |
| POST | `/api/v1/jobs/manual` | 建档并切割 |
| POST | `/api/v1/jobs/auto` | 建档并检测 |
| GET | `/api/v1/jobs/{job_id}` | 轮询 Job |
| POST | `/api/v1/jobs/{job_id}/cut` | 仅 auto：preview 后切割 |
| POST | `/api/v1/jobs/{job_id}/publish` | 返回切片 OSS 对象列表 |
| GET | `/api/v1/segments/{id}/preview\|thumb\|download` | 片段媒体（隐藏） |

### 1.3 推荐调用顺序

```text
GET  /api/v1/health
POST /api/v1/videos/import                 → video_id, status=importing
GET  /api/v1/videos/{video_id}             → 轮询至 ready
# 手动
POST /api/v1/jobs/manual                   → job_id
GET  /api/v1/jobs/{job_id}                 → done
POST /api/v1/jobs/{job_id}/publish         → all[].oss_url / selected[].oss_url
# 自动
POST /api/v1/jobs/auto                     → job_id
GET  /api/v1/jobs/{job_id}                 → preview
POST /api/v1/jobs/{job_id}/cut
GET  /api/v1/jobs/{job_id}                 → done
POST /api/v1/jobs/{job_id}/publish
```

### 1.4 耗时与轮询（本次实测 · source_media/1.mp4 · ~31 s 竖屏）

| 步骤 | 建议轮询 | 本次实测 |
|---|---|---|
| health | — | **0.02 s** |
| import 提交 | — | **0.006 s** |
| import → ready | 1～2 s | **40.9 s**（URL 流式转存 OSS + probe + 波形） |
| GET /media（整文件） | — | **0.41 s** 起传（约 104 MB） |
| GET /filmstrip | — | **5.9 s** |
| manual 提交 | — | **0.005 s** |
| manual → done（2 段） | 2～3 s | **19.6 s** |
| manual 对象列表（2 段） | — | **5.9 s** |
| auto → preview（content，1 镜） | 2～3 s | **46.7 s** |
| cut → done（1 段） | 2～5 s | **46.7 s** |
| auto 对象列表（1 段 ~58 MB） | — | **22.4 s** |

轮询建议：导入 **1～2 s**；任务 **2～3 s**。

## 二、通用结构

### 2.1 成功响应

| 字段 | 类型 | 描述 |
|---|---|---|
| code | integer | `0` 成功 |
| message | string | 多为 `"ok"` |
| data | object / array | 业务数据 |

### 2.2 错误响应

| 字段 | 类型 | 描述 |
|---|---|---|
| code | integer | 业务错误码（非 0） |
| message | string | 可读说明 |
| data | object | 常含 `request_id`；校验失败可有 `detail` |

HTTP 状态与 `code` 大致对应：`400`/`404`/`409`/`422`/`503` 等。

### 2.3 主键约定

| 资源 | 路径参数 | 响应主键 |
|---|---|---|
| Video | `{video_id}` | `video_id` |
| Job | `{job_id}` | `job_id` |
| Segment | `{segment_id}` | `segment_id` |

Job **不嵌套**完整 Video；用 `Job.video_id` 再调 `GET /videos/{video_id}`。

## 三、核心对象

### 3.1 ImportSubmitted（`POST /videos/import`）

| 字段 | 类型 | 描述 |
|---|---|---|
| video_id | string | UUID |
| status | string | 多为 `importing` |
| oss_key | string \| null | `oss_key` 导入时有值 |
| source_url | string \| null | `url` 导入时有值 |

### 3.2 Video（`GET /videos/{video_id}`）

| 字段 | 类型 | 描述 |
|---|---|---|
| video_id | string | UUID |
| status | string | `importing` \| `ready` \| `failed` |
| progress | number | 0～100 |
| message | string | 状态文案 |
| filename | string | 文件名 |
| duration / width / height / fps / codec / size_bytes | number… | ready 后有值 |
| preview_url | string \| null | 见 §3.3 |
| filmstrip_url | string \| null | 本机胶片条绝对 URL |
| waveform | object \| null | `{bins, peaks, has_audio}` |
| has_audio | boolean | 是否有音轨 |
| oss_key | string \| null | oss_key 导入时 |
| source_url | string \| null | url 导入时 |

**状态机**：`importing` → `ready`；或 → `failed`。

### 3.3 源片 `preview_url` 规则

| 导入方式 | `preview_url` |
|---|---|
| 传 `url` / `oss_url` | 后端转存到 `OSS_INGEST_PREFIX/{video_id}/source.ext`，预览由媒体入口决定 CDN 或签名 OSS |
| 传 `oss_key` | 直接使用前端提供的配置桶对象键；预览由媒体入口决定 CDN 或签名 OSS |
| 兜底 | `{API_PUBLIC_BASE 或请求 Host}/api/v1/videos/{id}/media` |

`filmstrip_url` 使用稳定 API 入口，媒体字节通过 302 直接来自 OSS。

> Windows 前端 + Linux API：这些稳定 API 媒体入口只负责 302，浏览器随后直接读取 OSS/CDN；私有 OSS 需正确配置 CORS 与 Range。

### 3.4 Job

| 字段 | 类型 | 描述 |
|---|---|---|
| job_id / video_id | string | UUID |
| mode | string | `manual` \| `auto` |
| status | string | 见状态机 |
| progress | number | 0～100 |
| message | string | 说明 |
| created_at | string | ISO8601 |
| segments | array | Segment 列表 |
| publish_action | object \| null | `done` 时 `{method:"POST", href}` |

**手动**：`pending` → `processing` → `done` \| `failed`
**自动**：`pending` → `detecting` → `preview` →（`/cut`）→ `processing` → `done` \| `failed`

### 3.5 Segment

| 字段 | 类型 | 描述 |
|---|---|---|
| segment_id / job_id | string | UUID |
| index | integer | 从 1 |
| start_time / end_time | number | 秒 |
| start_frame / end_frame | integer \| null | 帧 |
| oss_key | string \| null | **切割完成后即有**，指向源目录下 `clips/` 对象 |
| oss_url | string \| null | 切片 OSS/CDN 或签名访问地址 |
| download_url | string \| null | **切割完成后即有**（OSS/CDN 或 API 入口） |
| preview_url / thumb_url | string \| null | 切割完成即从 `clips/` OSS 对象预览 |
| download_filename | string \| null | 建议文件名 |
| source | string | `manual` \| `auto` |
| confidence / summary | number/string \| null | auto 常见 confidence |
| status | string | `preview` \| `done` \| `failed` 等 |

## 五、源片与视频

### 5.1 提交导入（实测提交 0.006 s）

```http
POST /api/v1/videos/import
Content-Type: application/json
```

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| oss_key | string | 二选一 | 配置 `OSS_BUCKET` 内对象键；别名 `oss-key` / `key` |
| url / oss_url | string | 二选一 | 任意可访问 http(s)；SSRF 校验后流式转存到受管 OSS |

#### Request（url）

```json
{
  "url": "https://example-bucket.oss-cn-region.aliyuncs.com/source_media/1.mp4"
}
```

#### 成功（实测）

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "video_id": "bb476d75-e4b5-4f7d-8fea-bba9a554ca8d",
    "status": "importing",
    "oss_key": null,
    "source_url": "https://example-bucket.oss-cn-region.aliyuncs.com/source_media/1.mp4"
  }
}
```

记住 `video_id`，轮询 `GET /videos/{video_id}`。

#### 失败：同时传 key + url（实测 422）

```json
{
  "code": 42201,
  "message": "请只传 oss_key（或 oss-key）与 url 其中之一",
  "data": {
    "request_id": "307d28c1-b320-4bc7-bb95-6f50c2156825",
    "detail": ["…"]
  }
}
```

#### 失败：SSRF（实测 400）

```json
{
  "code": 40003,
  "message": "url 目标地址不允许（内网或保留地址）",
```

## 六、手动切片

### 6.1 创建并切割（实测提交 0.005 s → done 19.6 s）

```http
POST /api/v1/jobs/manual
Content-Type: application/json
```

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| video_id | string | 是 | 已 `ready` 的视频 |
| segments | array | 是 | `{start, end}` 秒，至少 1 段 |

#### Request（实测）

```json
{
  "video_id": "bb476d75-e4b5-4f7d-8fea-bba9a554ca8d",
  "segments": [
    {"start": 0.0, "end": 5.0},
    {"start": 5.0, "end": 10.0}
  ]
}
```

#### 提交响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "job_id": "11c5cf52-fb14-4bc3-8be6-9634dd522e90",
    "video_id": "bb476d75-e4b5-4f7d-8fea-bba9a554ca8d",
    "mode": "manual",
    "status": "pending"
  }
}
```

重切：再次 `POST /jobs/manual` 建**新** Job（不要改旧 Job）。

## 七、自动分镜

### 7.1 创建并检测（实测 → preview 46.7 s，1 个分镜）

```http
POST /api/v1/jobs/auto
Content-Type: application/json
```

| 参数 | 类型 | 必填 | 描述 |
|---|---|---|---|
| video_id | string | 是 | 已 ready |
| detector | string | 否 | 默认 `content`；`adaptive` / `semantic` |
| threshold | number | 否 | 默认 35（content/adaptive） |
| min_scene_len | number | 否 | 默认 2（秒） |
| sample_fps | number | 否 | 仅 semantic |

#### 提交响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "job_id": "e30d23eb-d8de-44c0-97d0-c568ac9243fd",
    "video_id": "bb476d75-e4b5-4f7d-8fea-bba9a554ca8d",
    "mode": "auto",
    "status": "pending"
  }
}
```

#### preview（实测）

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "job_id": "e30d23eb-d8de-44c0-97d0-c568ac9243fd",
    "mode": "auto",
    "status": "preview",
    "progress": 100.0,
    "message": "✓ 检测完成，共 1 个分镜，请确认后切割",
    "segments": [
      {
        "segment_id": "0be6f313-c95c-4d63-b6fa-747a8286edec",
        "index": 1,
        "start_time": 0.0,
        "end_time": 30.663967,
        "status": "preview",
        "preview_url": null,
        "thumb_url": null,
        "confidence": 1.0,
        "source": "auto"

    ],

```

> `preview` 阶段尚无成品文件；切割 `done` 后得到源目录 `clips/` 下的 OSS 预存对象与封面地址。

### 7.2 切割（实测 cut→done 46.7 s）

```http
POST /api/v1/jobs/{job_id}/cut
Content-Type: application/json
```

Body 可 `{}`（用当前 preview 分镜），或传 `segments` 覆盖。

提交后 `status` 多为 `processing`，轮询至 `done`。

## 九、片段媒体（二进制）

| 路径 | 实测 |
|---|---|

### 10.3 Windows 前端 + Linux API

前端目录为 `frontend/reference-ui/`，Linux 后端监听 `0.0.0.0:8010`。

1. Windows 启动前端：
   ```powershell
   cd frontend\reference-ui
   npm install
   npm run dev -- --host 0.0.0.0 --port 5173
   ```
2. 推荐建立 SSH 隧道，让 Windows 的 `127.0.0.1:8010` 转发到 Linux 后端：
   ```powershell

   ```
3. 也可以将 `frontend/reference-ui/vite.config.ts` 中的 proxy `target` 改为 Linux API 地址，并在防火墙放行 `8010`。
4. 传 `url` 导入时，服务先流式转存受管 OSS，浏览器从 OSS/CDN 预览；胶片条和本机片段预览仍通过 API 代理。

## 十二、最小联调脚本（与本次实测一致）

```javascript
const BASE = "http://127.0.0.1:8010"; // 或公网 API

async function api(method, path, body) {
  const r = await fetch(BASE + path, {
    method,
    headers: body ? { "Content-Type": "application/json" } : undefined,
    body: body ? JSON.stringify(body) : undefined,
  });
  const j = await r.json();
  if (j.code !== 0) throw new Error(j.message || JSON.stringify(j));
  return j.data;
}

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

// 1) import by url
let v = await api("POST", "/api/v1/videos/import", {
  url: "https://example-bucket.oss-cn-region.aliyuncs.com/source_media/1.mp4",
});
while (true) {
  v = await api("GET", `/api/v1/videos/${v.video_id}`);
  if (v.status === "ready") break;
  if (v.status === "failed") throw new Error(v.message);
  await sleep(1500);
}
// v.preview_url === 源 url；胶片用 v.filmstrip_url

// 2) manual
let job = await api("POST", "/api/v1/jobs/manual", {
  video_id: v.video_id,
  segments: [
    { start: 0, end: 5 },
    { start: 5, end: 10 },
  ],
});
while (true) {
  job = await api("GET", `/api/v1/jobs/${job.job_id}`);
  if (job.status === "done") break;
  if (job.status === "failed") throw new Error(job.message);
  await sleep(2000);
}

// 3) 获取全部/选中切片 OSS 对象列表（不执行复制）
const pub = await api("POST", `/api/v1/jobs/${job.job_id}/publish`, {
  segment_ids: [job.segments[0].segment_id],
});
// pub.all[].oss_url / pub.selected[].oss_url → CDN 或签名 URL
```
