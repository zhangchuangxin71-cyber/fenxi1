# 新员工数据使用规范：五条必须守住的边界

数据规范的价值不在于条文数量，而在于员工遇到具体场景时知道什么可以做、什么必须先确认。以下要求适用于日常办公中的基础数据处理。

## 账号不得混用

个人账号只供本人使用，不把密码发给同事，也不使用他人账号临时处理工作。发现异常登录后，应立即修改密码并通知管理员。

## 文件按范围共享

发送文件前确认接收人和共享范围。包含客户信息、内部经营数据或未公开方案的文件，不得通过个人网盘和私人聊天工具外发。

## 权限按需申请

员工只申请完成当前工作所需的最小权限。临时权限在任务结束后及时回收，不因为以后可能使用而长期保留。

## 外发必须复核

对外发送材料前检查附件、收件人和敏感字段。无法判断是否可以外发时，先暂停发送并向负责人确认。

> 先确认再发送，比事后追回更可靠。

## 离岗完成交接

岗位调整或离职时，按照清单移交文件、账号和设备，管理员同步回收系统权限。交接完成后不得继续保留业务数据副本。
