# 老街修表店的最后一个学徒

清晨七点，林师傅照例推开木门，把柜台上的放大镜擦亮。玻璃窗外的街道换了几轮招牌，只有墙上的钟还保持着不同的节奏。

## 从一只停走的旧表开始

小周第一次来店里时，带着祖父留下的机械表。林师傅没有立刻报价，而是让他听机芯里断续的声音。那天之后，小周每个周末都来旁观。

## 学会慢下来

拆开一枚机芯只要几分钟，把零件放回正确位置却需要耐心。小周最初总想加快速度，林师傅只说：手快之前，眼睛要先看明白。

> 修表不是和时间赛跑，而是把失去的节奏找回来。

## 店里有了新的记录

小周开始为每只旧表拍照，记录故障、零件和修复过程。他没有改变林师傅的手艺，只是让多年经验第一次变得可以查找、可以传下去。

## 一块招牌继续亮着

林师傅退休那天，没有举行仪式。他把钥匙放在柜台上，指了指墙上那排钟。第二天清晨，小周照常开门，街坊们听见熟悉的滴答声从店里传出来。
