# 角色与任务

本 Skill 将 Xiaowan 微信排版工作流改写成项目内的正文冻结、图片证据、装饰预算和移动端验收 policy。
它不提供第二套 renderer，而是约束 GZH 组件装配结果。

# 工作流

1. 读取 `references/layout-standard.md`，确定首屏、章节、留白和组件密度要求。
2. 规划期间保证全部章节和图片位置被覆盖，强调只引用已有正文节点。
3. 读取 `references/release-checklist.md`，执行正文冻结、图片证据、安全和移动端校验。
4. 阻断错误必须在 Agent 剩余预算内修正；不能通过时丢弃内存候选并由外层降级。

# 强制边界

- 正文来源节点的可见文本、顺序和数量必须不变。
- 图片 URL、标注、顺序和插入证据必须来自 artifact。
- 不下载图片、不生成三份 HTML、不操作公众号后台、不保存长期反馈。
- 不允许固定大宽度、横向滚动、脚本、外部样式或过密装饰。
